## Screenshot Tips

- **Resolution**: Use 1920x1080 or higher for best quality
- **Format**: PNG format preferred for clarity
- **Content**: Ensure no personal/sensitive information is visible
- **Lighting**: Use light mode for consistency
- **Browser**: Hide browser UI for cleaner screenshots (F11 fullscreen)

## How to Take Screenshots

### Option 1: Using Browser DevTools
1. Open the application in Chrome/Edge
2. Press F12 to open DevTools
3. Press Ctrl+Shift+P (Cmd+Shift+P on Mac)
4. Type "screenshot" and select "Capture screenshot"

### Option 2: Using macOS
1. Press Cmd+Shift+4
2. Select the area to capture
3. Find the screenshot on your desktop

### Option 3: Using Windows
1. Press Windows+Shift+S
2. Select the area to capture
3. Screenshot will be in clipboard
